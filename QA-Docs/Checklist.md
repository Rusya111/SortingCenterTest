# Чек-лист проверок

Просто список того, что нужно не забыть проверить. Иду сверху вниз.

## Главная страница и навигация
- [ ] Открывается без ошибок (нет 500-й)
- [ ] В заголовке отображается текущий город (например, "Список заказов - Уфа")
- [ ] В таблице видны только заказы текущего города
- [ ] Скрытые заказы не видны в основной таблице
- [ ] Кнопка "Новый заказ" ведет на форму создания
- [ ] Кнопка "Скрытые заказы" ведет на страницу скрытых заказов
- [ ] Смена города в шапке обновляет список заказов и заголовок
- [ ] Если заказов нет, показывается нормальное сообщение (а не просто пустая белая страница)

## Поиск
- [ ] Поиск по полному номеру заказа (например, UF-1001)
- [ ] Поиск по номеру грузоместа (CN-12345)
- [ ] Поиск по части номера (например, "UF" или "123")
- [ ] Поиск, когда введен только пробел (не должен ломаться)
- [ ] Поиск, когда ничего не найдено (должно вывести сообщение, что пусто)
- [ ] При поиске не сбрасывается текущий город (остаемся в Уфе, а не перекидывает в дефолт)

## Создание заказа
- [ ] Открывается форма создания, поля пустые
- [ ] Все обязательные поля помечены (звездочкой или как-то еще)
- [ ] Пробую отправить пустую форму - вылезают ошибки валидации, ничего не создается
- [ ] Ввожу очень длинный номер заказа (символов 50) - не падает ли сайт?
- [ ] Выбор СЦ отгрузки и СЦ поставки из выпадающего списка работает
- [ ] Выбор статуса и проблемы из списков
- [ ] После создания редиректит на главную, заказ появился в таблице
- [ ] Кнопка "Отмена" возвращает на главную, заказ НЕ создается
- [ ] Дата создания проставляется автоматически и сохраняется корректно (смотрел в DBeaver, время в UTC)

## Редактирование заказа
- [ ] При открытии формы подтягиваются текущие данные заказа
- [ ] Меняю номер грузоместа, сохраняю - изменения применились
- [ ] Пробую стереть обязательное поле и сохранить - вылезает ошибка
- [ ] После сохранения редиректит на главную, данные в таблице обновились

## Скрытие и восстановление
- [ ] Нажимаю на "глазик" (скрыть) - заказ пропадает из основного списка
- [ ] Заказ появился на странице "Скрытые заказы"
- [ ] На странице скрытых нажимаю "показать" - заказ вернулся на главную
- [ ] Состояние скрытия сохраняется после перезагрузки страницы (F5)
- [ ] Если скрыть все заказы, на главной показывается сообщение, что пусто

## Удаление
- [ ] Нажимаю на корзину - вылезает окно подтверждения (confirm)
- [ ] Нажимаю "Отмена" в окне - заказ не удаляется
- [ ] Нажимаю "ОК" - заказ удален из таблицы
- [ ] Проверил в БД (через DBeaver) - записи реально нет, а не просто скрыта
- [ ] После удаления редиректит на главную с уведомлением "Заказ успешно удален"

## Разное (то, что заметил по ходу)
- [ ] В консоли браузера (F12) нет красных ошибок при загрузке страниц
- [ ] В сети (Network) при создании заказа улетает POST запрос, а не GET
- [ ] Проверил, что без токена CSRF удаление не проходит (для этого пришлось руками в DevTools удалить скрытое поле)
- [ ] Проверил отображение на разрешении 1366x768 (мой ноут) - таблица не разъезжается
