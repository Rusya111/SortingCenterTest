# Чек-лист проверок

Список того, что нужно не забыть проверить. Отмечено по итогам первого прогона; пункты, требующие контрольного регресса, оставлены пустыми. Иду сверху вниз.

## Главная страница и навигация
- [x] Открывается без ошибок (нет 500-й)
- [x] В заголовке отображается текущий СЦ (например, «Список заказов — Уфа»)
- [x] В таблице видны только заказы текущего СЦ (BUG-03 исправлен)
- [ ] Скрытые заказы не видны в основной таблице (перепроверить с поиском — TC-20)
- [x] Кнопка «Новый заказ» ведёт на форму создания
- [x] Кнопка «Скрытые заказы» ведёт на страницу скрытых заказов
- [x] Смена СЦ в шапке обновляет список заказов и заголовок
- [x] Если заказов нет, показывается нормальное сообщение (не пустая страница)

## Поиск
- [x] Поиск по полному номеру заказа (например, `UF-1001`)
- [x] Поиск по номеру грузоместа (`CN-12345`)
- [x] Поиск по части номера (`UF`, `123`) — частичное совпадение работает (BUG-01 исправлен)
- [ ] Поиск, когда введён только пробел (не должен ломаться)
- [x] Поиск, когда ничего не найдено (выводится сообщение, что пусто)
- [x] При поиске не сбрасывается текущий СЦ (остаёмся на выбранном)
- [ ] Поиск на странице скрытых заказов отправляет ровно один запрос (BUG-15 — проверить по Network, TC-26)

## Создание заказа
- [x] Открывается форма создания, поля пустые
- [x] Обязательные поля помечены
- [x] Пустая форма — ошибки валидации, ничего не создаётся
- [x] Очень длинный номер заказа (50+ символов) — сайт не падает (замечание: `MaxLength` в планах)
- [x] Выбор СЦ отгрузки и СЦ поставки из выпадающих списков работает
- [ ] В дропдаунах СЦ полный список (все 8 СЦ) — BUG-08, TC-22
- [ ] Создание с одинаковыми СЦ блокируется с ошибкой — BUG-06, TC-21
- [ ] На форме нет поля «Дата создания», дата проставляется автоматически (UTC) — BUG-13/14, TC-25
- [x] Выбор статуса и проблемы из списков работает
- [x] После создания редирект на главную, заказ появился в таблице
- [x] Кнопка «Отмена» возвращает на главную, заказ НЕ создаётся

## Редактирование заказа
- [x] При открытии формы подтягиваются текущие данные (BUG-02 исправлен)
- [x] Меняю номер грузоместа, сохраняю — изменения применились (и в БД)
- [x] Пустое обязательное поле — ошибка валидации, данные не меняются
- [x] После сохранения редирект на главную, данные в таблице обновились
- [ ] Внизу страницы Edit нет «висячей» фигурной скобки — BUG-17, TC-27

## Просмотр деталей (Details)
- [ ] В строке заказа есть кнопка Details — BUG-10, TC-24
- [ ] Карточка открывается, данные совпадают с таблицей и БД

## Статусы в таблице
- [ ] Колонка «Статус» отображается — BUG-09, TC-23
- [ ] Статусы показываются цветными бейджами, различимы глазами

## Скрытие и восстановление
- [x] «Глазик» (скрыть) — заказ пропадает из основного списка
- [x] Заказ появился на странице «Скрытые заказы»
- [x] «Показать» — заказ вернулся на главную (BUG-04 исправлен)
- [ ] Состояние скрытия сохраняется после перезагрузки страницы (F5)
- [ ] Если скрыть все заказы, на главной показывается сообщение, что пусто

## Удаление
- [x] Корзина — окно подтверждения (confirm) появляется
- [x] «Отмена» в окне — заказ не удаляется
- [ ] «ОК» — заказ удалён из таблицы, в БД записи нет (BUG-05 закрыт как Cannot Reproduce — подтвердить на актуальной сборке, TC-13)
- [ ] После удаления редирект на главную с уведомлением «Заказ успешно удален»

## Разное (заметил по ходу)
- [x] В консоли браузера (F12) нет красных ошибок при загрузке страниц
- [x] При создании заказа улетает POST-запрос, а не GET
- [x] Без CSRF-токена удаление не проходит (проверено руками в DevTools)
- [x] Отображение на 1366x768 — таблица скроллится горизонтально (UX-замечание, не баг)
