# One more sorting center

Пет-проект на ASP.NET Core. Сайт для учета заказов в сортировочном центре. Делал для себя, чтобы разобраться с бэкендом и потом самому же его потестировать.

## Что это вообще такое

Сайт позволяет сотрудникам разных сортировочных центров (Уфа, Грибки, Екатеринбург и тд) вести учет проблемных заказов. Можно создавать, редактировать, искать и скрывать заказы. У каждого пользователя свой город, и он видит только свои заказы.

Стек:
- Бэкенд: C#, ASP.NET Core MVC
- База: PostgreSQL + Entity Framework (Code First)
- Фронт: Bootstrap 5, немного jQuery для валидации
- Иконки: Font Awesome

## Что реализовано

- Таблица заказов с фильтром по текущему городу (пользователю)
- Поиск по номеру заказа и номеру грузоместа (можно ввести часть номера)
- Добавление нового заказа. Есть валидация на клиенте и на сервере
- Редактирование заказа
- Удаление заказа (с подтверждением, чтобы случайно не нажать)
- Скрытие заказа (soft delete). Скрытые заказы уходят на отдельную страницу, оттуда их можно вернуть
- Переключение между городами через выпадающий список в шапке
